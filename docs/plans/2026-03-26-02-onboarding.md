# Onboarding Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build the conversational onboarding flow where an AI agent asks 4 questions, user picks from chips or types custom answers, and responses are saved to the user store.

**Architecture:** Single page component at `/onboarding` containing a chat-style conversation. State machine tracks current question index. Each answer saves to local state, then bulk-commits to user-store on completion. Sidebar is visible but disabled (already handled by Sidebar component).

**Tech Stack:** Next.js, Framer Motion (message animations), Zustand (user-store)
